# 2024_Prospective_EHI_GI_paradigm

This repository contains data analysis scripts for publication 'Gastrointestinal microbiota and barrier integrity in individuals who develop exertional heat illness and pair-matched controls' by Gould et al. (2026). DOI:   

Folder/file description:  

**6msm_info**/*prospective_analysis_manuscript_6msm_info_gh.Rmd*: R markdown script used to analyse 6-mile speed march descriptives. 

**16S_case_con**/*prospective_analysis_manuscript_16S_case_con_gh.Rmd*: R markdown script used to analyse 16S rRNA sequencing output for exertional heat illness cases vs. matched controls.  

**16S_sev**/*prospective_analysis_manuscript_16S_sev_gh.Rmd*: R markdown script used to analyse 16S rRNA sequencing output for only the severe exertional heat illness cases vs. matched controls.

**biomarkers**/*prospective_analysis_manuscript_biomarkers_gh.Rmd*: R markdown script used to analyse biomarkers for exertional heat illness cases vs. matched controls.  

**biomarkers_sev**/*prospective_analysis_manuscript_biomarkers_sev_gh.Rmd*:  R markdown script used to analyse biomarkers for only the severe exertional heat illness cases vs. matched controls.

**characteristics**/*prospective_analysis_manuscript_characteristics_gh.Rmd*: R markdown script used to analyse participant characteristics.  

**control_matching**/*control_matching_gh.R*: R script used for control matching.  

**severe_biochem**/*prospective_analysis_manuscript_severe_biochem_gh.Rmd*: R markdown script used to analyse serum creatine and alanine transaminase of the severe exertional heat illness cases.
